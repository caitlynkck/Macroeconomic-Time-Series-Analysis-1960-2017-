# Macroeconomic-Time-Series-Analysis-1960-2017-
Analyzed CAR GDP, exports, and population (1960–2017) using ARIMA &amp; VAR models. Applied log transformations &amp; differencing for stationarity, selected models via AIC/BIC, and ran diagnostics. Explored cross-correlations &amp; impulse responses, revealing GDP-exports links and population independence, generating 2-year forecasts.

This project analyzes the time series of GDP, exports, and population in the Central African Republic (1960–2017) using Python. The analysis includes:

Data preprocessing: Log transformations and differencing for stationarity.

Univariate modeling: ARIMA models selected via AIC/BIC with diagnostic checks.

Multivariate modeling: VAR(2) model to capture joint dynamics and cross-correlations.

Impulse Response Functions (IRFs): Evaluated the effect of shocks on GDP, exports, and population.

Forecasting: Generated 2-year ahead predictions with 95% confidence intervals.

The study provides insights into economic trends, relationships among key indicators, and forecasting, useful for policymakers and economic planning.
