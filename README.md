# Macroeconomic-Time-Series-Analysis-1960-2017-
Analyzed CAR GDP, exports, and population (1960–2017) using ARIMA &amp; VAR models. Applied log transformations &amp; differencing for stationarity, selected models via AIC/BIC, and ran diagnostics. Explored cross-correlations &amp; impulse responses, revealing GDP-exports links and population independence, generating 2-year forecasts.
